Which data can be reused?

How this edition was captured. The editing kit includes time-stamped agency responses, the county’s rendered Sunday bulletin and the two FHP entries for the SR 46 crossing. The browser captures preserve agency values and retrieval times. Response headers were unavailable.

NWS county warnings Direct JSON

Request /alerts/active?zone=FLC117 for Seminole County. The two records used here both carried that county code. A forecast-zone-only query can miss county-coded river warnings. Keep the CAP ID, affected area, event, update chain, sent time, expiration and event end. A null end can accompany “until further notice.” Follow replacements and cancellations. Distinguish a successful empty list from a failed request.

County feed · API guide

NWS river gauges Direct JSON

Pair /gauges/{lid} with /gauges/{lid}/stageflow at the NWPS v1 API. Use GENF1 and SNFF1 locally, COCF1 for upstream context. Join by gauge ID. The metadata provides thresholds and impact statements. The series supplies primary stage in feet, observation time, forecast issuance and forecast valid times. Missing flow fields included negative sentinel values. Check units and missing codes before plotting. The captured vertical-datum field was empty. A verified datum would be needed to compare stages with surveyed elevations. USGS also supplies observations to NWPS, so a matched station can share the same underlying sensor.

NWPS API documentation · Lake Harney series

USGS continuous monitoring Direct GeoJSON

Query the OGC latest-continuous/items collection by monitoring_location_id=USGS-… and parameter_code=00065 (gage height). Four sites returned data. Parse numeric strings, retain units, observation time, qualifiers, approval status and geometry. Reject future times and withhold observations older than the pilot’s two-hour window. Check time-series identity if a site returns multiple records. The Lake Jesup response shows why a successful HTTP request or recent edit cannot establish freshness.

USGS API documentation

NWS rainfall statements JSON envelope, parsed text

Search the products API for type=PNS, location=MLB and a bounded issuance window. Five products were returned in the 72-hour search ending at 1:44 pm Nov 22. The chosen rainfall bulletin, NOUS42 KMLB 210108, contained 18 Seminole rows. Preserve product ID, station, county, duration code, unit, network and end time. The API records 8:08 pm Nov 20 for issuance and the text header reads 8:07 pm. The embedded CSV-style section is optional and its format can change. Hold unmatched rows for review.
