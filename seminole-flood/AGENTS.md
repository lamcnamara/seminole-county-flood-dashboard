# Seminole County flood dashboard

The issued page is `Seminole-County-Flooding-Impact-Dashboard.html` beside this folder. The [project guide](README.md) covers manual capture, editing, verification, issuing a candidate and rollback. The [register](project.json) contains the source IDs, expansion queue and dated history.

Start from the editing kit embedded in the issued page. Change the template, renderer or reviewed data there, then rebuild. Keep the source snapshot and data edition ID when making a presentation-only change. Record the maintenance date in the project history.

Before issuing, compare the two headline stages with their station cards and archived observations. Exercise the map, road and rain filters, saved checklist and both downloads at desktop and phone widths. Rebuild from the downloaded kit to verify the handoff. For the next data edition, begin with the replacement NWS messages and the county and state road notices listed in the [guide](README.md#next-data-review).
